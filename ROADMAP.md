# Roadmap

Before a first release: retain the passing final-runtime security gate, review/maintain the upstream SQLite package and retain the verified patched source setup/startup floor; execute the prepared hosted Kubernetes 1.35–1.37 matrix on native amd64 (the local amd64 app ran under QEMU); authorise a limited live-provider evaluation and review unsupported claims; verify ingress/TLS; enable private reporting and review release signing/provenance. Local Kubernetes 1.35.8 baseline and 1.36.4/1.37.0 current Linux arm64 incident acceptance and same-schema PVC backup/restore/config upgrade/rollback have passed. Physical storage loss and future schema migrations still need their own evidence. See docs/release-readiness.md.

Next release priorities should follow that evidence. Candidate improvements include stronger workload ownership navigation, more complete crash-log interpretation, deterministic EndpointSlice readiness comparisons, retention/export ergonomics and an identity-provider integration with explicit per-user permissions. These are planned, not implemented. Multi-cluster control, autonomous remediation, billing and operators are outside the first release.
