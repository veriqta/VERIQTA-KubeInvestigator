Kubernetes maintained versions were derived from [official releases](https://kubernetes.io/releases/) on 2026-11-01. A target range is not a certification. Client 37 is selected for this modest range; both native arm64 local and native amd64 hosted version matrices now have incident acceptance. No EKS, AKS, GKE, OpenShift, enterprise, air-gapped or GPU claim is made. No managed service is required. Exact scopes, image identities, fixture corrections and scan DB metadata are in [current evidence](security/findings/2026-11-02-source-compatibility.json). An emulated execution is not a native architecture result. [Hosted run 41473405003](acceptance/2026-11-02-hosted-validation.json) adds actual amd64 source/Kubernetes/recovery and both native image results, including exact scanner/database/image identity records.

Initial setup downloads Python packages, base/application/sample images and kind nodes. Live mode requires HTTPS to api.openai.com; the app also needs its Kubernetes API and cluster DNS. Restricted-network operators can mirror reviewed wheels/images and configure image repositories and private-registry pulls via their infrastructure, but must validate digests/architectures and provider egress. An offline live-model deployment is not supported. A StorageClass, ingress controller, TLS certificates, DNS records and enforcing CNI are operator-supplied where used.
