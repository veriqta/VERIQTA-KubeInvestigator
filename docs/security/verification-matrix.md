# Security verification matrix

This matrix separates source review, local mock/component tests, browser checks, real-cluster acceptance, live-provider evaluation and external review. It is not an independent audit or certification. See the latest [runtime acceptance record](../runtime-acceptance.md) for actual cluster execution outcomes; source assertions alone never establish an installed RBAC pass.

| Exact Kubernetes permissions / credential overreach | chart rbac.yaml, collector.py allowlist; smoke.py restricted kubeconfig | `bash scripts/smoke.sh`; disposable kind only | Real Kubernetes 1.35.8 run passed restricted reads/denials, including actual log denial; no production access |
